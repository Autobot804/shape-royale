# SHAPE ROYALE — เกมยิงเอาชีวิตรอด

เกมแนว battle royale สไตล์ **Simple Shape** เล่นได้ในเบราว์เซอร์ ด้วยไฟล์ HTML ไฟล์เดียว
ผู้เล่น 20 คน (คุณ + บอท 19 ตัว) ต่อสู้ในแผนที่เดียว เขตปลอดภัยหดตัวลงเรื่อย ๆ เหลือรอดคนสุดท้ายเพียงคนเดียว

> เกมนี้ได้แรงบันดาลใจจากเกมยิงเอาชีวิตรอดยอดนิยม แต่สร้างกราฟิกและโค้ดขึ้นใหม่ทั้งหมด
> ไม่ได้ใช้ภาพ เสียง หรือทรัพย์สินใด ๆ ของเกมต้นแบบ

## เริ่มเล่น

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย (ดับเบิลคลิก) ไม่ต้องติดตั้งอะไรเพิ่ม

ถ้าอยากรันผ่าน local server:

```bash
# Python
python -m http.server 8000

# หรือ Node.js
npx serve .
```

แล้วเปิด http://localhost:8000

## Deploy ขึ้น GitHub Pages

### วิธีที่ 1: ผ่านหน้าเว็บ GitHub (ง่ายที่สุด)

1. สร้าง repository ใหม่ (public) เช่น `shape-royale`
2. อัปโหลด `index.html` (และ `README.md`) ขึ้น repo
3. ไปที่ **Settings → Pages**
4. หัวข้อ **Build and deployment**
   - Source: `Deploy from a branch`
   - Branch: `main` และโฟลเดอร์ `/ (root)`
5. กด **Save** รอ 1–2 นาที
6. เกมจะออนไลน์ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

> ไฟล์ต้องชื่อ `index.html` และอยู่ที่ root ของ repo เพื่อให้ Pages เปิดเป็นหน้าแรกอัตโนมัติ

### วิธีที่ 2: ผ่าน Git CLI

```bash
git init
git add index.html README.md
git commit -m "Add SHAPE ROYALE game"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/<ชื่อ-repo>.git
git push -u origin main
```

จากนั้นเปิด Pages ตามขั้นตอนในวิธีที่ 1 (หรือใช้ `gh api` / `gh repo edit --enable-pages`)

### หมายเหตุการ deploy

- ไม่ต้องมี build step, ไม่มี dependency, ไม่มี API key — เป็น static site ไฟล์เดียว
- ไม่ต้องมีไฟล์ `.nojekyll` เพราะไม่มีโฟลเดอร์ที่ขึ้นต้นด้วย `_`
- เกมมีเสียง (WebAudio) ซึ่งเบราว์เซอร์จะเปิดให้หลังผู้เล่นกดปุ่มเริ่มเกมแล้วเท่านั้น
- ใช้ได้ทั้ง GitHub Pages, Netlify, Vercel, Cloudflare Pages หรือเปิดไฟล์ในเครื่อง

## ปรับแต่งเกม

แก้ค่าที่ต้นไฟล์สคริปต์ใน `index.html`:

- `const WORLD = 2800;` — ขนาดแผนที่
- `const BOT_COUNT = 19;` — จำนวนบอท (ผู้เล่นทั้งหมด = BOT_COUNT + 1)
- `const WEAPONS = { ... }` — ดาเมจ, ความเร็วกระสุน, ขนาดแม็ก, เวลาบรรจุกระสุน
- `makeZone()` — รัศมีโซนเริ่มต้น, เวลารอ, ความเร็วการหด, ดาเมจโซน
- `damage()` — มีตัวคูณลดดาเมจจากบอท (`amount *= 0.68`) ปรับเพื่อความยากง่าย
