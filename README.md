# ZONE ROYALE — เกมยิงเอาชีวิตรอด

เกมแนว battle royale มุมมอง top-down เล่นได้ในเบราว์เซอร์ ด้วยไฟล์ HTML ไฟล์เดียว
ผู้เล่น 20 คน (คุณ + บอท 19 ตัว) ต่อสู้บนเกาะร้าง เขตปลอดภัยหดตัวลงเรื่อย ๆ เหลือรอดคนสุดท้ายเพียงคนเดียว

> เกมนี้ได้แรงบันดาลใจจากเกมยิงเอาชีวิตรอดยอดนิยม แต่สร้างกราฟิกและโค้ดขึ้นใหม่ทั้งหมด
> ไม่ได้ใช้ภาพ เสียง หรือทรัพย์สินใด ๆ ของเกมต้นแบบ

## งานภาพ

กราฟิกทั้งหมดวาดด้วย Canvas 2D แบบ procedural ไม่มีไฟล์ภาพเลย (นอกจากฟอนต์จาก Google Fonts)

- **ตัวละคร** มองจากด้านบนแบบ 3/4: หมวกกันน็อกพร้อมชิลด์หน้า, เสื้อเกราะพร้อมสายรัด, เป้, สนับเข่า, รองเท้าบู๊ต
  แขนและปืนหันตามทิศเล็ง ขาเดินตามทิศการเคลื่อนที่ (เดิน/ยืน/พุ่งตัวมีอนิเมชันต่างกัน)
- **อาวุธ 4 แบบ** วาดแยกสัดส่วนจริง ปืนพก, SMG, ไรเฟิลพร้อมกล้องเล็ง, ช็อตกัน
- **แผนที่**: หลังคาบ้านแบบ hip roof มีหน้าต่าง/ประตู/ปล่องไฟ/แอร์บนดาดฟ้า, ถังไม้, ถังน้ำมัน,
  กระสอบทราย, ก้อนหิน, พุ่มไม้, ต้นไม้ใบเป็นกระจุก, ถนนลูกรังพร้อมรอยล้อ
- **เอฟเฟกต์**: ไฟปากกระบอกปืน, ควัน, ปลอกกระสุนกระดอน, รอยเลือด, ศพที่ลอยอยู่, ฝุ่นจากการวิ่ง,
  เงาตกกระทบ, vignette, แสงแดดอุ่น และภาพสั่นเมื่อยิง/โดนยิง
- **HUD**: แบบเกมยิงมืออาชีพ — minimap วาดจากแผนที่จริง, แถบเลือด, อาวุธ+กระสุน, kill feed, ตัวเลขผู้รอด

> ตัวละครและฉากทั้งหมดประกอบขึ้นจากรูปทรงเรขาคณิตหลายชั้น ไม่ใช่ไฟล์ภาพหรือ sprite sheet
> จึงโหลดเร็ว ไม่มีปัญหา 404 และแก้สี/รายละเอียดได้ในโค้ด

## เริ่มเล่น

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย (ดับเบิลคลิก) ไม่ต้องติดตั้งอะไรเพิ่ม

ถ้าอยากรันผ่าน local server:

```bash
# Python
python -m http.server 8000

# หรือ Node.js
npx serve .
```

แล้วเปิด http://localhost:8000

## Deploy ขึ้น GitHub Pages (อัตโนมัติด้วย GitHub Actions)

repo นี้มี workflow [.github/workflows/deploy-pages.yml](.github/workflows/deploy-pages.yml)
ที่จะ deploy เกมขึ้น Pages ให้เองทุกครั้งที่ push เข้า branch `main`

### ตั้งค่าครั้งแรก

1. สร้าง repository (public) บน GitHub แล้ว push โค้ดขึ้นไป

   ```bash
   git remote add origin https://github.com/<ชื่อผู้ใช้>/<ชื่อ-repo>.git
   git push -u origin main
   ```

2. ไปที่ **Settings → Pages**
3. หัวข้อ **Build and deployment → Source** เลือก **`GitHub Actions`**
   (ห้ามเลือก `Deploy from a branch` เพราะ workflow นี้เป็นตัว deploy เอง)
4. ไปที่แท็บ **Actions** จะเห็น run ชื่อ **Deploy game to GitHub Pages**
   - ถ้ายังไม่เริ่ม ให้กด **Run workflow** (workflow ตั้ง `workflow_dispatch` ไว้)
5. รอ ~1 นาที เกมจะออนไลน์ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

### หลังจากนั้น

push เข้า `main` ทุกครั้ง → เกมเวอร์ชันใหม่ขึ้นอัตโนมัติ (ดูสถานะได้ที่แท็บ Actions)
URL ของเว็บจะแสดงในหน้า run ที่ job `deploy` ด้วย

### ทางเลือก: deploy จาก branch (ไม่ใช้ Actions)

ถ้าไม่อยากใช้ workflow ให้ลบ `.github/workflows/deploy-pages.yml` แล้วตั้ง
**Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `/ (root)`**
แทน — ได้ผลเหมือนกัน แต่จะอัปเดตช้ากว่าและไม่มี log ให้ดู

> ไฟล์ต้องชื่อ `index.html` และอยู่ที่ root ของ repo เพื่อให้ Pages เปิดเป็นหน้าแรกอัตโนมัติ

### หมายเหตุการ deploy

- ไม่ต้องมี build step, ไม่มี dependency, ไม่มี API key — เป็น static site ไฟล์เดียว
- ไม่ต้องมีไฟล์ `.nojekyll` เพราะไม่มีโฟลเดอร์ที่ขึ้นต้นด้วย `_`
- เกมมีเสียง (WebAudio) ซึ่งเบราว์เซอร์จะเปิดให้หลังผู้เล่นกดปุ่มเริ่มเกมแล้วเท่านั้น
- ใช้ได้ทั้ง GitHub Pages, Netlify, Vercel, Cloudflare Pages หรือเปิดไฟล์ในเครื่อง

## ปรับแต่งเกม

แก้ค่าที่ต้นไฟล์สคริปต์ใน `index.html`:

- `const WORLD = 2800;` — ขนาดแผนที่
- `const BOT_COUNT = 19;` — จำนวนบอท (ผู้เล่นทั้งหมด = BOT_COUNT + 1)
- `const WEAPONS = { ... }` — ดาเมจ, ความเร็วกระสุน, ขนาดแม็ก, เวลาบรรจุกระสุน
- `makeZone()` — รัศมีโซนเริ่มต้น, เวลารอ, ความเร็วการหด, ดาเมจโซน
- `damage()` — มีตัวคูณลดดาเมจจากบอท (`amount *= 0.68`) ปรับเพื่อความยากง่าย
